1 · Roster

Add a Player

Find a profile ID by searching the player on aoe2companion.com. Without one, their games cannot be auto-detected.

2 · Ratings

Change a Player's Elo

Ratings are calculated from match results automatically. Overriding one is rarely needed — normally only to correct a rating that went wrong. The change applies immediately and affects team balancing for everyone.

Sets this player's rating now. Future match results move it from there.

Confirm change

This affects the leaderboard and team balancing straight away. It can be undone later with Remove existing override.

3 · Recorded games

Exclude Games From Elo

Excluding a game keeps it in history and on the History page but drops it from the rating replay. Nothing is deleted, so this is always reversible.

4 · Discarded games

Games The Importer Skipped

Games in the generated feed that did not pass the import gates. Lobby names must contain one of (case-insensitive). Including a game overrides the gate and imports it on the next check.

5 · Backup

Export All Data

Downloads players, full match history, and overrides as JSON. Because the database accepts writes from anyone, this download is your only real safety net — keep a recent one. The file can be loaded back by appending ?localSandbox=1 to any page URL.
